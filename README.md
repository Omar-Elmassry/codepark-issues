# CodePark issues

This is the public place to report bugs and ideas for **CodePark**, a free interview-practice app.

The app's code is private, so issues live here.

## How to report

- **A bug:** open a [new issue](../../issues/new). Say what happened, what you expected, and the steps to get there. The "Report a bug" link in the app fills in the page, app version and browser for you.
- **A wrong answer or unclear question:** use the **Report** button on that question or problem in the app. It is the fastest way.
- **Anything else:** use the contact form in the app.

Please do not post passwords, emails or other private data here. Everything on this page is public.
